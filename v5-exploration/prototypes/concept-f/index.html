03 / AI engineering

Software Factory turns model work into accountable engineering work.

The central proof is architecture: agents run inside a system whose state, verification, and authority do not depend on them.

Public proof / control plane

Workers are disposable. Workflow truth is durable.

Codex and Claude Code implement provider-specific process adapters. The domain stores plans, runs, evidence, reviews, approvals, and release lineage independently.

ZERO AUTONOMOUS RELEASE AUTHORITY
PLANproposal → deterministic DAG validation → approval-bound digest
IMPLEMENTworkspace-scoped worker with default-deny environment
VERIFYfixed commands; process facts remain separate from model prose
REVIEWindependent principal; strict fail-closed verdict parsing
SQLITE / durable state
REPAIR / bounded iteration
SUPERVISOR / zero-spend policy + persisted backoff
