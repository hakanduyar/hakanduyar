# HDU Profile V5 — Architecture-First Design Exploration

This directory is an isolated design study. It does not generate or replace the production GitHub profile README.

## Boundaries

- Branch: `feat/hdu-profile-v5-architecture`
- Production `README.md`: unchanged
- Live `main`: unchanged
- V4 source and evidence: historical reference only
- Output: six browser prototypes, a scored critique, and three refined finalists for owner selection

## Preview

Run `node v5-exploration/server.mjs` from the repository root, then open `http://127.0.0.1:4195/v5-exploration/prototypes/`.

Every concept accepts `?theme=dark` or `?theme=light`. Layout is responsive at 760 px and below.

## Review artifacts

- `research/engineering-inventory.md` — evidence-based positioning and capability tiers
- `research/critique.md` — ten-dimension scoring and refinement notes
- `research/finalist-notes.md` — GitHub feasibility for the final three
- `evidence/render-audit.json` — 24 real-browser responsive/theme checks
- `evidence/finalist-1/` through `finalist-3/` — dark/light desktop/mobile evidence
- `FINAL-REPORT.md` — owner-selection report; production stops here
