# V4 design system

## Identity

The public identity is the full name **Hakan Duyar**. A circular signal nucleus acts as the abstract signature; no initial-based monogram is needed. This avoids ambiguity around `HD` and deliberately retires the rejected `HDU` and polygon/hexagon directions.

## Hybrid direction

- **Flight** provides aerospace calibration, motion, and technical confidence.
- **Signal** exposes relationships between interface, systems, delivery, operations, motion, and AI-assisted work.
- **Spatial** provides premium restraint through composed architecture layers and generous empty space.

The selected-systems scene combines a mission path with relationship links. Architecture uses spatial layers. Public telemetry combines disciplined measurement with a signal trace. Light mode is quieter and product-oriented; dark mode carries more of the aerospace/signal atmosphere.

## Master timeline

The animated hero is one SVG and one seamless 12-second loop:

1. `00.0–03.3s` — Mode 01 / Flight
2. `03.3–07.8s` — Mode 02 / Signal
3. `07.8–11.7s` — Mode 03 / Spatial
4. `11.7–12.0s` — return to Flight

Short transition-field bursts make the state changes legible. The identity nucleus remains stable across all modes. Reduced-motion users receive a separate static Flight asset rather than a paused animated document.
