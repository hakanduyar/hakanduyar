# GitHub compatibility

- All public visuals are repository-local SVG files; there are no third-party statistic cards, remote images, scripts, or embedded fonts.
- Every SVG has a responsive `viewBox`, an image role, a title, and a description. Fixed root dimensions are removed during optimization.
- The README keeps only the hero visible, then places systems, architecture, and signal inside one native `<details>` disclosure. Its `<summary>` contains only a repository-local responsive picture (`expand-dark.svg` with `expand-mobile-dark.svg` at the mobile breakpoint), so the control has no native typed label, sanitizer-added image link, or separate application behavior. Scene images use GitHub-preserved top alignment and adjacent picture boundaries stay compact, eliminating the inline baseline strip between dark canvases. There is no theme control, linked button, light asset, or `prefers-color-scheme` source; every SVG carries its own opaque dark canvas so the composition stays dark in every GitHub appearance mode.
- Reduced-motion sources appear first so they win when motion reduction and the mobile breakpoint both match. Systems, architecture, and signal use separate dark mobile sources at the GitHub-column-aware 1080 px breakpoint.
- The visible README body remains image-only: one top-level hero picture and the disclosure; the disclosure summary is one image and its content is systems, architecture, and signal. There are no native Markdown headings, paragraphs, lists, badges, separators, links, or typed summary text. Descriptive `alt` text remains for accessibility.
- Hero, systems, architecture, and public signal use SVG CSS only. Every scene has a separate fully static asset with no keyframes or animation declarations; lower scenes also have purpose-built mobile animated/static assets.
- The validator rejects scripts, `foreignObject`, image embedding, external resources, fixed dimensions, oversized assets, credentials, the retired polygon/`HDU` identity, missing transition semantics, and missing collision-audit hooks.
- Scene renderers assert protected canvas, text, node, trajectory, and layer zones before assets are emitted. Tests cover all six desktop/mobile geometry specifications; browser evidence then checks rendered SVG text and path geometry at 890 px and 390 px.
- Browser collision evidence carries a digest of every generated SVG. CI rejects stale evidence, missing required widths, frame coverage below the V4.2 threshold, or any recorded overlap, geometry hit, or out-of-bounds text.
- Generated outputs are deterministic from committed source and `data/telemetry.json`; network access is limited to the explicit telemetry refresh command.
